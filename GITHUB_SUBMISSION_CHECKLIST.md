# GitHub Submission Checklist

Before submitting the repository:

- [ ] `package.json` is in the repository root.
- [ ] `README.md` is present.
- [ ] `node_modules/` is NOT uploaded.
- [ ] `.env` is NOT uploaded.
- [ ] Local SQLite database files are NOT uploaded.
- [ ] Run `npm install` after cloning.
- [ ] Run `npm start` and verify `http://localhost:3000`.
- [ ] Test login, registration, posting, search, follow, comments, notifications and settings.
- [ ] Submit the GitHub repository URL requested by your course/task portal.
